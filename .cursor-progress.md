## 1. Τι είναι το project

**SmartOrder** = B2B SaaS πλατφόρμα QR-code παραγγελιοληψίας για την ελληνική εστίαση (HoReCa).
Χτίζεται **πάνω** στο έτοιμο Laravel script **QuickQR v2.4** (CodeCanyon-style menu/QR builder),
το οποίο επεκτείνουμε με:
- Σύνδεση με τοπικά POS (API-only, μέσω local agent bridge).
- 100% προπληρωμή (Stripe + Viva Wallet).
- Menu sync από POS + αυτόματη μετάφραση.
- Πολυγλωσσικό customer UI (EL/EN/BG/TR).

Ο πλήρης σχεδιασμός/κανόνες είναι στο `.cursorrules` — **πάντα τήρησέ τους** (ιδίως: μην πειράζεις core αρχεία, Service layer, νέα migrations μόνο, Redis για τον agent poll, idempotency).

## 2. Τεχνολογικό stack

- **Backend:** Laravel 10 (PHP `^8.1`, δοκιμασμένο σε 8.2).
- **DB:** MySQL, table prefix **`qr_`** (μέσω `DB_PREFIX` στο `.env`, config `core/config/database.php`).
- **Cache/Queue (στόχος):** Redis (το `.env` έχει `REDIS_HOST` έτοιμο· προς το παρόν `CACHE_DRIVER=file`, `QUEUE_CONNECTION=sync`). **Δεν** υπάρχει ακόμα `predis/phpredis` στο composer — θα χρειαστεί για το agent bridge.
- **Πληρωμές (υπάρχοντα gateways):** `stripe/stripe-php ^12`, PayPal, Razorpay, Mollie, Paytm, Paystack, κ.ά. (16 controllers στο `PaymentMethods/`). **Viva Wallet δεν υπάρχει ακόμα.**
- **i18n:** `mcamara/laravel-localization` + custom DB-backed `Language` model + JSON `translations` στα μοντέλα μενού.
- **Frontend:** Blade templates (themes), Bootstrap, TinyMCE, Vite.
- **Σχετικά libs:** `cviebrock/eloquent-sluggable`, `guzzlehttp/guzzle`.

## 4. Domain model (βασικές οντότητες & σχέσεις)

Ορολογία: **"Post" = Εστιατόριο/Restaurant** (το μοντέλο λέγεται `Post`, οι routes `restaurants.*`).

- `User` ─< `Post` (restaurants). Ένας χρήστης (ιδιοκτήτης) έχει πολλά εστιατόρια.
- `Post` (εστιατόριο):
  - `menu_categories()` → `MenuCategory` (με `subcategories` self-ref μέσω `parent`, `menus`).
  - `image_menus()` → `ImageMenu` (μενού ως εικόνα).
  - `tables()` → `RestaurantTable` (τραπέζια για on-table QR).
  - `options()` → `PostOption` (key/value ρυθμίσεις ανά εστιατόριο· βλ. helper `post_options()`).
- **Μενού:** `MenuCategory` ─< `Menu` (items). Κάθε `Menu`:
  - `variants()` → `MenuVariant` (τιμές ανά συνδυασμό), `variantOptions()` → `MenuVariantOption`, `extras()` → `MenuExtra`.
  - Έχει JSON column **`translations`** (cast object) με `{lang: {title, description}}`. Accessors `getNameAttribute`/`getDescriptionAttribute` επιστρέφουν μετάφραση βάσει cookie `Quick_user_lang_code`. **`getOriginal('name')`** δίνει το αμετάφραστο (ελληνικό) original — χρησιμοποιείται στα order emails/whatsapp.
- **Παραγγελίες:** `Order` ─< `OrderItem` ─< `OrderItemExtra`.
  - `Order` πεδία: `restaurant_id`, `type` (on-table|takeaway|delivery), `customer_name`, `table_number`, `phone_number`, `address`, `status` (**pending|completed|unpaid**), `message`, `seen` (bool), `is_paid` (bool), `payment_gateway`, `created_at`. `timestamps=false`.
  - `OrderItem`: `order_id, item_id, quantity, variation`. Σχέση `menu`, `itemExtras`, `variant`.
- **Λοιπά:** `WaiterCall`, `Allergy`, `Coupon`, `Tax`, `Country`.
- **SaaS:** `Plan` ─< `PlanOption`, `Transaction` (πληρωμές — και συνδρομές ΚΑΙ order payments), `Upgrade`, `PaymentGateway`, `Subscriber`.
- **CMS/Marketing:** `Blog`, `BlogCategory`, `BlogComment`, `Page`, `Faq`, `Testimonial`, `Adsense`, `Notification`, `Language`, `Option` (global settings).

## 5. Βασικές ροές (όπως είναι ΣΗΜΕΡΑ στο vanilla QuickQR)

### 5α. Δημιουργία/διαχείριση εστιατορίου & μενού
- Routes υπό auth: `restaurants` resource + `User\PostController` (~2381 γραμμές, ο πυρήνας).
- QR builder, menu CRUD (categories/subcategories/items/variants/extras/image menus), tables CRUD — όλα AJAX endpoints.

### 5β. Public view & παραγγελία πελάτη
- `GET /{slug}` → `User\PostController@publicView` (η δημόσια σελίδα μενού QR).
- `POST /{restaurant}/send-order` → `sendOrder()`:
  - Validation: `items, name, ordering-type(on-table|takeaway|delivery), table|phone|address, pay_via`.
  - Δημιουργεί `Order` + `OrderItem` + `OrderItemExtra`, υπολογίζει `amount` (τιμή variant/extra × qty + delivery charge).
  - Αν `pay_via == pay_online`: `Order.status = 'unpaid'` και δημιουργεί `Transaction` (`transaction_method='order'`, `user_id=restaurant_id`, `product_id=order_id`) → επιστρέφει URL `payment.index`.
  - Αλλιώς (π.χ. WhatsApp/cash): στέλνει email στον ιδιοκτήτη, προαιρετικά WhatsApp deep-link (plugin `quickorder`).
- `POST /{restaurant}/call-waiter` → `callTheWaiter()`.

### 5γ. Πληρωμή παραγγελίας (υπάρχουσα, customer-facing)
- `GET /payment/{transaction}` → `User\PaymentController@index` (διαλέγει gateway από `PostOption` flags).
- `POST /payment/{transaction}/pay` → δυναμικά καλεί `PaymentMethods\{Gateway}Controller::pay()`.
- `PaymentController::paySuccess($transaction)`: `Order.is_paid=1`, `status='pending'`, ενημερώνει wallet του εστιατορίου, redirect στο public view, διαγράφει το transaction.
- **IPN/Webhooks:** `ANY /ipn/{gateway}`, `POST /webhook/{gateway}` → `PaymentMethods\PaymentController@ipn|webhook`.

### 5δ. Dashboard παραγγελιών (ιδιοκτήτης)
- `GET /orders/{restaurant?}` → λίστα (εξαιρεί `status=unpaid`), polling/AJAX για νέες (`seen=0`).
- `GET /heartbeat` → μετράει αν υπάρχουν αόρατες (`seen=0`, όχι unpaid) παραγγελίες (ηχητική ειδοποίηση).
- `completeOrder` (status→completed), `deleteOrder`. Παλιές `unpaid` παραγγελίες >3h διαγράφονται αυτόματα.

### 5ε. SaaS συνδρομές
- `CheckoutController` (αγορά plan), `SubscribeController` (cancel), `TransactionController` + invoices.
- Admin panel (prefix από `admin_url()`, middleware `admin`+`demo`): πλήρες CRUD για users, plans, gateways, languages, blogs, pages, settings, plugins κλπ.

### 5στ. i18n (υπάρχον)
- Customer μενού: cookie `Quick_user_lang_code` + JSON `translations` ανά item.
- UI strings: `core/lang/<code>/lang.php` (EL/EN ~785 strings, υπάρχουν & bg/tr/ar/fr).
- Επιλογή locale: `mcamara/laravel-localization` ή custom `quickcms.localize` (ανάλογα `settings.include_language_code`).

## 9. Σημαντικές συμβάσεις / παγίδες (gotchas)

- **ΜΗΝ τροποποιείς core:** `core/app/Http/Controllers/`, `core/routes/`, υπάρχοντα `core/database/migrations/`. Νέα λογική → νέα αρχεία (Services, νέα routes files, νέες migrations).
- **Redis keys:** `agent:{business_token}:queue` (list), `agent:{business_token}:last_seen` (string).
- **Agent poll = O(1) από Redis**, ΠΟΤΕ από MySQL.
- **Νόμιμες αποδείξεις (ΑΠΥ/ΔΑΑ):** ΜΟΝΟ από το τοπικό POS. Εμείς = pre-order/kitchen ticketing.
- **POS integration:** ΜΟΝΟ μέσω επίσημων REST APIs. ΟΧΙ direct DB injection (SQL Server/Firebird).
- `Order.status` σήμερα έχει enum **pending|completed|unpaid** — για prepaid θα χρειαστεί νέα κατάσταση/πεδία (`payment_status=pending/paid`, `sync_status`) μέσω νέας migration (μην αλλάξεις το υπάρχον enum in-place).
- Το `Transaction` εξυπηρετεί **και** συνδρομές **και** order payments (διάκριση με `transaction_method`).
- Global helpers στο `core/app/Http/Helpers/Helper.php` (π.χ. `post_options()`, `___()` για μεταφράσεις, `active_theme()`, `quick_alert_*`). Αν χρειάζεσαι util, τσέκαρε εκεί πρώτα.
- Το prefix `qr_` εφαρμόζεται από Laravel — στα migrations/queries γράφεις ΧΩΡΙΣ prefix (π.χ. `posts`, όχι `qr_posts`).
- Μετάφραση μενού: `translations` JSON + cookie `Quick_user_lang_code`. Για ωμό κείμενο χρησιμοποίησε `getOriginal()`.
